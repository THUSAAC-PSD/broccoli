# Codelink 晋级赛

Codelink 上午场使用 `codelink-qualifier` 比赛类型。选手自由选题，每道题的计分名额只授予最先通过该题的若干名选手；在规定数量的不同题目上获得名额后即晋级下午场，参加 [Codelink 淘汰赛](./codelink-bracket.md)。

## 安装插件

安装 Broccoli 的开发依赖后，在仓库根目录运行以下命令。

```bash
pnpm --filter @broccoli/web-sdk build
just build-plugin plugins/codelink-qualifier --install
```

构建产物为 `plugins/codelink-qualifier/codelink_qualifier.wasm`，前端包位于 `plugins/codelink-qualifier/frontend/dist`。服务器从插件目录加载插件，插件目录默认为 `./plugins`。重启服务器，或前往管理后台的**插件**页面，单击 **Reload All**，加载该插件。

## 创建比赛

1. 在比赛编辑页面，将比赛类型设为 `codelink-qualifier`，并设置上午场的开始时间和结束时间。
2. 添加题目。每道题需配置测试数据，以及相应的评测器、检查器和语言插件。
3. 为全部选手报名。榜单只显示已报名的选手。

## 设置规则

在管理后台打开该比赛的 **Configure** 对话框，选择 `codelink-qualifier` 插件的 `contest` 配置。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| **Expected Problem Count**（`expected_problem_count`） | 16 | 预期题数。实际题数与此不符时，页面显示提示。设为 0 时不检查。 |
| **Scoring Slots per Problem**（`slots_per_problem`） | 2 | 每题名额数，即每道题最多有几名选手获得计分名额。 |
| **Credited Problems to Qualify**（`solves_to_qualify`） | 2 | 晋级题数，即选手需在几道不同的题目上获得名额。 |
| **Scoreboard Refresh Interval**（`scoreboard_refresh_seconds`） | 5 | 榜单自动刷新间隔，单位为秒。设为 0 时只能手动刷新。 |

默认配置对应常规的上午场，共 16 道题，每题 2 个名额，获得 2 道题的名额即晋级。每题名额数和晋级题数的取值范围为 1～1000，预期题数为 0～1000，刷新间隔为 0～3600，均为整数。预期题数只用于显示提示，规则中的题数以比赛实际包含的题目为准。

配置应在开赛前完成。修改保存后，下一次刷新时生效，榜单按新配置重新计算，无需重新构建插件。

## 晋级规则

名额按提交时间先后授予，规则如下。

1. AC 提交按提交时间排序；提交时间相同时，提交 ID 小者在前。评测完成的先后不影响排序。
2. 同一选手在同一题上只计第一次 AC。
3. 选手未晋级时，该次 AC 占用该题的一个空余名额；该题名额已满时，不再授予名额。
4. 选手获得名额的题数达到晋级题数后即晋级，已获得的名额保留。此后的 AC 仍显示在榜单上，但不占用名额，也不改变晋级时间。

未获得名额的 AC 不计入晋级题数。已晋级的选手不再参与名额分配，其后通过该题的选手依次递补。以默认配置为例，结果如下表所示。

| 事件 | 结果 |
| --- | --- |
| Alice 获得 A、B 两题的名额 | Alice 晋级，保留这两个名额 |
| Alice 随后通过 C 题 | 显示该 AC，C 题的 2 个名额仍空余 |
| Bob、Carol 随后通过 C 题 | 两人各获得 C 题的 1 个名额 |
| Dave 随后通过 C 题 | 显示该 AC，不授予名额 |

只统计上午场时间内的提交。截止前提交、截止后才完成评测的代码，仍可获得名额。练习提交及比赛时间外的提交不占用名额。评测出错或题目缺少测试数据时，不判为 AC。

## 比赛进行中

选手可在**比赛主页**查看规则说明，其中的数值与当前配置一致。**排行榜**页面上方为各题的名额占用情况，下方每名选手一行，显示计分题数和晋级状态。

| 状态 | 说明 |
| --- | --- |
| **已确认晋级** | 无论剩余评测结果如何，该选手均已晋级 |
| **评测未完成，无法确认是否晋级** | 尚有评测未完成，其结果可能决定该选手能否晋级 |

其他选手不显示晋级状态，可在**计分题数**一列查看进度。晋级人数和晋级时间只统计**已确认晋级**的选手。

榜单按配置的间隔自动刷新，上午场结束后继续刷新，直至排队中的评测全部完成。关闭**自动刷新**开关可暂停刷新，单击**刷新**可立即更新。刷新间隔为 0 时，页面显示**仅手动刷新**。

## 评测延迟或出错

出现以下任一情况时，选手显示为**评测未完成，无法确认是否晋级**。

- 该选手本人的提交仍在评测。
- 其他选手更早的提交尚未出结果，且可能占用该选手所需的名额。

仍在排队的提交同样视为未完成。不影响结果的提交不会延迟其他选手的判定，包括名额已满的题目上的提交、已 AC 题目上的重复提交，以及已晋级选手的提交。

晋级结果确定后，即显示**已确认晋级**，其他评测是否完成不影响这一判定。在这些评测完成前，该选手的名额和时间仍可能变化。

重测和配置修改生效后，榜单重新计算。未生效的重测不改变正式结果。

## 比赛结束后

所有提交评测完成、重测核对完毕后，标记为**已确认晋级**的选手即为晋级名单。插件不会自动为选手报名，晋级选手需手动加入 [Codelink 淘汰赛](./codelink-bracket.md)所用的比赛。

单次提交显示的分数只表示该代码是否通过，晋级资格以本榜单为准。
